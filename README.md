# Cyber Threat Analytics Platform and Incident Visualization System
🚀 Project Overview

This project was completed as part of our internship with Infosys Springboard Virtual Internship 7.0.

The Cyber Threat Analytics Platform is an interactive security analytics and incident visualization system designed to help both technical and non-technical audiences understand complex cybersecurity log data at a glance. The project uses Power BI, Power Query, and DAX to transform a 40,000-record cybersecurity incident dataset into meaningful insights through interactive dashboards, KPIs, and visual storytelling.

The project demonstrates how business intelligence and data analytics can be used to solve real-world security problems — surfacing attack patterns, severity trends, anomaly behavior, and response effectiveness through clear, data-driven visualizations.
