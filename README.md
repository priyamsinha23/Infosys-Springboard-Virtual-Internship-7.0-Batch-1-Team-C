# 📊 Cyber Threat Analytics Platform and Incident Visualization System
# 🚀 Project Overview

This project was completed as part of our internship with Infosys Springboard Virtual Internship 7.0.

The Cyber Threat Analytics Platform is an interactive security analytics and incident visualization system designed to help both technical and non-technical audiences understand complex cybersecurity log data at a glance. The project uses Power BI, Power Query, and DAX to transform a 40,000-record cybersecurity incident dataset into meaningful insights through interactive dashboards, KPIs, and visual storytelling.

The project demonstrates how business intelligence and data analytics can be used to solve real-world security problems — surfacing attack patterns, severity trends, anomaly behavior, and response effectiveness through clear, data-driven visualizations.

 Key numbers:
- 🔢 40,000 cybersecurity incidents analyzed
- 📊 7 interactive dashboards
- 🌍 28 states covered

# 🚀 Key Features

- 📊 **Interactive Multi-Dashboard Framework**: Seven themed Power BI dashboards covering attacks analysis, threat detection, network traffic, user behaviour, and severity/response — each with slicers and cross-filtering for deep exploration.
- 🔍 **Threat Detection & Anomaly Analysis**: Identifies attack patterns and anomaly behaviour across 40,000 incidents using a custom-built Anomaly Score Band logic.
- 🧠 **Advanced DAX-Driven KPIs**: Derived metrics like % High Severity, Block Rate %, and Anomaly Bands that hold accurately under every filter and slicer combination.
- ⚙️ **Clean, Optimized Data Pipeline**: Raw Kaggle data shaped through 19 Power Query steps (type correction, null handling, date/time splitting, category standardisation) for a fast, responsive model.
- 📈 **Rich Visual Storytelling**: Decomposition tree, ribbon chart, treemap, and Sankey visuals turn complex log data into clear, actionable insights for both technical and non-technical audiences.

# 📊 Project Workflow

1. **Data Collection** – Sourced the "Cyber Security Attacks" dataset from Kaggle, containing 40,000 cybersecurity incident records spanning 2020–2023.

2. **Data Cleaning & Preprocessing** – Cleaned and shaped the raw data through 19 Power Query steps, including data type correction, null handling, splitting date/time fields, and standardising attack and severity categories.

3. **Data Analysis** – Built a structured data model with a marked Date table and defined relationships, then authored core DAX measures — including the Anomaly Score Band logic — to quantify attack patterns, severity levels, and anomaly behaviour.

4. **Visualization / Development** – Designed seven themed Power BI dashboards (Attacks Analysis, Threat Detection & Anomaly Analysis, Network Traffic Analysis, User Behaviour Analytics, and Threat Profile & Severity/Response) using slicers, cross-filtering, decomposition tree, ribbon, treemap, and Sankey visuals.

5. **Insights & Interpretation** – Validated all figures across visuals and optimised model performance, surfacing key findings such as a near-even 3-way threat split (DDoS 33.6%, Malware 33.3%, Intrusion 33.2%), Windows as the most-targeted OS (~45%), and a clear response gap with only ~33.8% of attacks actively blocked.
